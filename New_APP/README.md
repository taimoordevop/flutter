## ✨ Features

<table>
  <tr>
    <td>📰 <strong>Live News</strong></td>
    <td>Fetches fresh articles via NewsAPI</td>
  </tr>
  <tr>
    <td>🎠 <strong>Trending Carousel</strong></td>
    <td>Auto-playing showcase of top stories</td>
  </tr>
  <tr>
    <td>🗂️ <strong>Categories</strong></td>
    <td>Filter by General, Business, Tech, Sports, and more</td>
  </tr>
  <tr>
    <td>🔍 <strong>Smart Search</strong></td>
    <td>Find articles with a slick animated search bar</td>
  </tr>
  <tr>
    <td>🌗 <strong>Theme Toggle</strong></td>
    <td>Switch between light and dark modes, saved via Hive</td>
  </tr>
  <tr>
    <td>📴 <strong>Offline Reading</strong></td>
    <td>Cache articles for offline access</td>
  </tr>
  <tr>
    <td>🌐 <strong>WebView Integration</strong></td>
    <td>Read articles in-app or open in browser</td>
  </tr>
  <tr>
    <td>📱 <strong>Responsive UI</strong></td>
    <td>Material 3 design for all screen sizes</td>
  </tr>
</table>

- Flutter SDK (3.x or higher)
- Dart SDK
- Android Studio / VS Code
- NewsAPI Key (Get one from [newsapi.org](https://newsapi.org/))
